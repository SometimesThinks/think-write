- 이 커밋은 기능 추가보다도 사용자가 실제로 보는 MVP 화면을 더 제품처럼 보이게 정리한 작업이다.
- 언어 설정과 디버그 정보를 메인 입력 흐름에서 분리하면서, 글쓰기 중심 화면을 유지하려는 방향이 더 선명해졌다.
- 특히 디버그 패널을 토글로 숨긴 구조는 이후 실제 Ghost Complete를 붙여도 디버그 UI가 제품 UI를 방해하지 않게 만든다.
