# Ghost 렌더링 좌표 오차 정리

- 작성일: 2026-04-03
- 상태: 미해결
- 관련 범위: ghost complete, cursor position, editor overlay

## 1. 문제 상황

현재 ghost text는 editor 안에 absolute overlay로 렌더링하고 있다.

이때 `selection.from === selection.to`인 collapsed selection 상태에서는
해당 position을 "현재 커서 위치"로 보고 ghost를 그린다.

하지만 실제 화면에서는 ghost text의 위아래 높이가
커서가 있는 텍스트 줄과 완전히 맞지 않는 문제가 있다.

즉,

- 좌우 위치는 비교적 비슷하게 맞지만
- 상하 위치는 어긋나 보일 수 있다.

---

## 2. 현재 구현 방식

현재 위치 계산은 아래 순서로 한다.

1. `selection.from` 위치를 읽는다.
2. `editor.view.coordsAtPos(selection.from)`로 해당 position의 화면 좌표를 얻는다.
3. editor surface의 `getBoundingClientRect()`를 읽는다.
4. 둘의 차이를 구해서 editor 내부 상대 좌표로 바꾼다.
5. 그 위치에 ghost overlay를 absolute로 렌더링한다.

즉 현재 방식은
**caret position 기반 좌표 계산 + absolute overlay 렌더링**이다.

---

## 3. 왜 오차가 생길 수 있나

현재 구현은 "커서의 좌표"와 "텍스트가 실제로 보이는 baseline"을
동일한 것으로 가정하고 있다.

하지만 실제로는 이 둘이 다를 수 있다.

가능한 원인은 아래와 같다.

1. `coordsAtPos()`가 주는 값은 caret rectangle 기준 좌표다.
2. ghost text는 editor의 실제 inline text flow 안이 아니라 별도의 absolute div에 그린다.
3. editor paragraph의 line box와 overlay div의 line-height / font metrics가 완전히 같지 않을 수 있다.
4. paragraph 내부 렌더링과 overlay 렌더링은 baseline 정렬 기준이 다를 수 있다.

즉,
**커서 좌표를 그대로 overlay top으로 쓰면 텍스트 줄 높이와 정확히 맞지 않을 수 있다.**

---

## 4. 이번에 확인한 핵심 개념

이번 이슈로 인해 아래 개념을 정확히 이해해야 한다는 점이 드러났다.

- `selection.from`, `selection.to`
- collapsed selection과 range selection 차이
- `editor.view.coordsAtPos(pos)`가 반환하는 좌표 의미
- paragraph node와 현재 커서가 속한 block 구조
- editor DOM 렌더링과 absolute overlay 렌더링의 차이
- line-height / baseline / caret rectangle의 차이

즉 이 문제는 단순 CSS 미세 조정이 아니라
**editor position model과 실제 텍스트 렌더링 모델을 같이 이해해야 하는 문제**에 가깝다.

---

## 5. 현재 판단

이 이슈는 충분히 기록할 가치가 있다.

이유는:

- ghost complete 구현에서 사용자 체감 품질에 직접 영향을 주고
- 이후 `Tab` accept / invalidation / 렌더링 안정화와도 연결되며
- 단순 수치 보정만으로 끝낼지, 렌더링 방식을 바꿀지 판단해야 하기 때문이다.

따라서 현재 단계에서는
**문제를 먼저 기록하고, 해결 방안은 실제 검토 후 별도로 추가**하는 것이 적절하다.

---

## 6. 해결 상태

현재는 문제 인식과 원인 후보까지만 정리한 상태다.

아직 확정되지 않은 항목:

- px 보정으로 해결 가능한지
- caret top 대신 다른 좌표 기준이 더 적절한지
- absolute overlay 방식 자체를 유지할지
- editor 내부 inline flow에 더 가까운 렌더링 방식으로 바꿔야 하는지

해결 방안은 실제 비교/검증 후 이 문서에 추가한다.
