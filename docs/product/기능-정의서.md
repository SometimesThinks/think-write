# ThinkWrite 기능 정의서

## 1. 학습 언어 설정

### 기능 설명

- 사용자의 모국어와 목표 언어를 설정하는 기능
- 설정값은 이후 AI 제안 요청에 함께 전달됨

### 사용자 흐름

- 사용자가 설정 화면에 진입함
- 모국어를 선택함
- 목표 언어를 선택함
- 설정을 저장함
- 이후 글쓰기 기능에서 해당 설정값이 반영됨

### 입력 항목

- 모국어
- 목표 언어

### 예외

- 필수 항목 미입력 시 저장 불가
- 지원하지 않는 언어 선택 불가

## 2. 고스트 자동 완성 (Ghost Autocomplete)

### 기능 설명

- 사용자가 글을 작성하는 도중 입력을 잠시 멈추면 현재 문맥을 바탕으로 다음 표현을 제안하는 기능
- 제안은 고스트 텍스트 형태로 편집기 내부에 표시됨

### 사용자 흐름

- 사용자가 텍스트를 입력함
- 입력이 짧게 멈추면 completion 요청 전송
- 응답 수신 시 고스트 텍스트 표시
- `Tab` 입력 시 제안 수락
- `Esc` 또는 추가 입력 시 제안 무효화

### 상태

- idle
- loading
- visible
- accepted
- dismissed
- invalidated

### 예외

- 커서 이동 시 기존 제안 무효화
- 새 입력 발생 시 이전 요청 취소
- 응답 지연 시 기존 입력 흐름 방해 금지

## 3. BYOK 설정

### 기능 설명

- 사용자가 직접 provider와 API Key를 등록하여 기능을 사용하는 설정 기능

### 사용자 흐름

- 사용자가 provider를 선택함
- API Key를 입력함
- 저장 요청 전송
- 저장 성공 시 이후 요청에 등록된 정보 사용

### 입력 항목

- provider
- API Key

### 예외

- 저장 시점에는 형식을 빡빡하게 검증하지 않고 즉시 로컬에 저장함 (Lazy Validation).
- 실제 글쓰기 도중 AI API 호출이 실패(예: 401 Unauthorized, 한도 초과 등)할 경우, 에디터 화면에 즉각적으로 오류 안내(Toast 등)를 표시하여 흐름 중단을 알림.
- 저장 실패(스토리지 에러 등) 시 기존 상태 유지
- Key 교체 및 삭제 가능해야 함
