# ThinkWrite 기능 정의서

## 1. 학습 언어 설정

### 기능 설명

- 사용자의 모국어와 목표 언어를 설정하는 기능
- 설정값은 이후 AI 제안 요청에 함께 전달됨

### 사용자 흐름

- 사용자가 설정 화면에 진입함
- 모국어를 선택함
- 목표 언어를 선택함
- 설정을 저장함
- 이후 글쓰기 기능에서 해당 설정값이 반영됨

### 입력 항목

- 모국어
- 목표 언어

### 예외

- 필수 항목 미입력 시 저장 불가
- 지원하지 않는 언어 선택 불가

## 2. 고스트 자동 완성 (Ghost Autocomplete)

### 기능 설명

- 사용자가 글을 작성하는 도중 입력을 잠시 멈추면 현재 문맥을 바탕으로 다음 표현을 제안하는 기능
- 제안은 고스트 텍스트 형태로 편집기 내부에 표시됨

### 사용자 흐름

- 사용자가 텍스트를 입력함
- 입력이 짧게 멈추면 completion 요청 전송
- 응답 수신 시 고스트 텍스트 표시
- `Tab` 입력 시 제안 수락
- `Esc` 또는 추가 입력 시 제안 무효화

### 상태

- idle
- loading
- visible
- accepted
- dismissed
- invalidated

### 예외

- 커서 이동 시 기존 제안 무효화
- 새 입력 발생 시 이전 요청 취소
- 응답 지연 시 기존 입력 흐름 방해 금지

## 3. Provider 연동 설정

### 기능 설명

- 앱 내부 설정 UI가 아니라 서버 `.env.local`을 통해 OpenAI provider를 연결하는 실행 환경 설정

### 사용자 흐름

- 저장소를 실행하는 사용자가 `.env.local`에 `OPENAI_API_KEY`를 입력함
- 서버가 실행 시 환경변수를 읽음
- 이후 completion 요청은 서버 환경변수의 Key를 사용해 처리됨
- 설정 누락 또는 인증 실패 시 전역 오류로 안내함

### 입력 항목

- `OPENAI_API_KEY`
- 필요 시 `OPENAI_MODEL` (기본값 `gpt-5-nano`)

### 예외

- API Key는 브라우저나 응답 본문에 재노출하지 않음.
- 환경변수 누락 시 completion은 전역 설정 오류로 처리함.
- 실제 글쓰기 도중 AI API 호출이 실패할 경우, API Key 인증 실패 같은 전역 문제는 Toast로 안내함.
- ghost 요청 실패나 무효화는 에디터 근처 inline notice 또는 무표시로 처리함.
