# ThinkWrite 요구사항 정의서

## 1. 프로젝트 개요

- 프로젝트명: ThinkWrite
- 프로젝트 성격: 오픈소스 기반 self-hosted AI 글쓰기 에디터
- 목표: 외국어 글쓰기 과정에서 표현 추천과 교정 지원을 편집기 내부에서 즉시 제공하는 글쓰기 도구 구현
- 운영 형태: 서버 `.env.local`에 provider API Key를 넣어 실행하는 self-hosted 방식

## 2. 핵심 요구사항

### 2.1 실시간 글쓰기 지원

- 사용자의 입력 흐름을 방해하지 않는 실시간 표현 제안 제공 필요.
- 제안은 편집기 내부에서 즉시 확인 가능해야 함.
- 사용자는 키보드 입력만으로 제안을 수락하거나 무시할 수 있어야 함.

### 2.2 글쓰기 중심 인터랙션

- 사용자는 별도 채팅 화면으로 이동하지 않고 편집기 내부에서 기능을 사용할 수 있어야 함.
- 표현 제안은 작성 중인 문맥을 기준으로 동작해야 함.
- 글쓰기 흐름 유지를 최우선 UX 기준으로 삼아야 함.
- 사용자의 사고 흐름 유지를 위해 불필요한 리치 텍스트 서식(볼드, 이미지 삽입 등) 기능은 배제하고 순수 텍스트 환경을 제공해야 함.

### 2.3 사용자 언어 설정 반영

- 사용자의 모국어와 목표 언어 설정을 지원해야 함.
- 설정값은 AI 요청에 반영되어야 함.
- 설정값은 서버 요청 시 일관되게 전달되어야 함.

### 2.4 provider 연동 운영

- 앱 내부에서 사용자별 API Key 등록 UI를 제공하지 않는다.
- provider API Key는 서버 `.env.local`에서만 관리해야 한다.
- 초기 MVP provider는 OpenAI로 고정한다.
- 초기 MVP 모델은 `gpt-5-nano`로 고정한다.
- 클라이언트는 API Key 원문을 알 수 없어야 한다.
- 추후 멀티 provider 확장이 가능하도록 adapter 구조는 유지해야 한다.

## 3. MVP 기능 요구사항

### 3.1 필수 기능

- 학습 언어 설정 제공
- 고스트 자동 완성 (Ghost Autocomplete) 제공
- `.env` 기반 provider 연동

### 3.2 고스트 자동 완성 요구사항

- 사용자가 입력을 잠시 멈추면 현재 문맥 기반 제안이 생성되어야 함.
- 제안은 고스트 텍스트 형태로 편집기 내부에 표시되어야 함.
- 사용자는 `Tab` 키로 제안을 수락할 수 있어야 함.
- `Esc` 입력 또는 추가 입력 발생 시 기존 제안은 무효화되어야 함.
- 정상 상태에서는 별도 알림보다 ghost text 표시가 우선되어야 함.
- provider 설정 누락 또는 API Key 인증 실패 같은 전역 문제는 toast 등 전역 알림으로 안내할 수 있어야 함.
- ghost 요청 실패/무효화는 editor 근처 inline notice 또는 무표시로 처리할 수 있어야 함.

### 3.3 학습 언어 설정 요구사항

- 사용자는 모국어를 설정할 수 있어야 함.
- 사용자는 목표 언어를 설정할 수 있어야 함.
- 설정값이 AI 요청 시 반영되어야 함.

### 3.4 provider 연동 요구사항

- 서버는 `OPENAI_API_KEY`를 환경변수에서 읽을 수 있어야 함.
- 시스템은 서버 환경변수에 설정된 Key를 기반으로 요청을 처리할 수 있어야 함.
- API Key는 브라우저 저장소나 클라이언트 응답에 노출되지 않아야 함.
- API Key 누락 또는 잘못된 Key 설정 시 사용자에게 오류를 안내할 수 있어야 함.
- 향후 다른 provider 추가 시 route 상위 계층을 크게 흔들지 않아야 함.

## 4. 비기능 요구사항

### 4.1 사용성

- 핵심 상호작용은 키보드 중심으로 빠르게 처리 가능해야 함.
- 편집 중인 텍스트 입력을 방해하지 않아야 함.

### 4.2 성능

- 제안 응답은 체감상 즉시 나타나는 수준 목표.
- 늦게 도착한 응답이 최신 입력 상태를 덮어쓰지 않아야 함.
- 불필요한 중복 요청 최소화 필요.

### 4.3 확장성

- provider 교체 및 추가가 가능한 구조 필요.
- 추후 재작성 기능, 문법 오류 표시 기능 확장이 가능해야 함.

## 5. MVP 범위

- 학습 언어 설정
- 고스트 자동 완성 (Ghost Autocomplete)
- `.env` 기반 provider 연동
