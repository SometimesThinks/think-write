# ThinkWrite 기획서

## 1. 기획 배경

- 영어 문서 및 공식 문서 독해는 가능하나, 생각을 영어로 자연스럽게 표현하는 데 어려움 존재.
- 영어 표현 능력 향상을 위한 반복적 영작 연습 필요.
- 말하기보다 글쓰기가 즉각적인 표현 교정 및 수정에 더 적합하다는 판단.
- 지속적인 영작을 위해서는 빠른 표현 추천 및 교정 지원 도구 필요.
- 집필 중 실시간 제안과 즉시 수정이 가능한 IDE형 글쓰기 에디터 필요.

## 2. 문제 정의

기존 외국어 글쓰기 도구 검토 결과, 다음과 같은 공통적 한계 확인.

- 외국어 글쓰기 중 표현 확인으로 인한 흐름 단절.
- 사후 교정 중심 구조로 인한 집필 중 지원 부족.
- 챗봇 기반 도구는 질문과 답변을 반복해야 해 글쓰기 흐름이 자주 끊김.
- 표현 추천, 교정, 설명 기능과 편집기 상호작용 간의 낮은 통합도.

## 3. 타겟 사용자

- 영어를 학습하는 한국인
- 외국어로 글을 작성하는 학습자

## 4. 핵심 가치 제안

- 글쓰기 흐름을 유지하는 인라인 UX 제공.
- 언어 학습 맥락을 반영한 실시간 표현 제안 제공.
- 불필요한 리치 텍스트 서식(볼드, 이미지 등)을 배제하여, 순수한 텍스트 입력과 사고의 흐름에만 집중할 수 있는 환경 제공.
- 오픈소스 + BYOK 기반의 유연한 운영 구조 제공.

## 5. 성공 기준

- 외부 번역기 또는 챗봇으로 이탈하지 않고 편집기 내부에서 글쓰기 지속 가능.
- 고스트 자동 완성(Ghost Autocomplete) 기능의 자연스러운 집필 흐름 내 동작.
- 최소한의 백엔드 계층으로 멀티 프로바이더 및 BYOK 확장 가능.

## 6. 범위

### MVP 범위

- 학습 언어 설정
- 고스트 자동 완성 (Ghost Autocomplete)
- BYOK 기반 provider 연동

### 확장 범위

- 선택 문장 재작성
- 문법 오류 밑줄 표시
- 고급 리치 텍스트 편집
